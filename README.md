# Chatbox

iOS messenger UI built with UIKit and VIPER architecture.

The project recreates the interface and interactions of a modern communication app:
- chats list
- stories section
- swipe actions
- collapsing header
- animated transitions
- relative timestamps
- custom UI components

Tech stack:
- UIKit
- Auto Layout
- VIPER
- UITableView / UICollectionView
- SF Symbols

The main goal of the project is to practice scalable iOS architecture and production-like UI implementation without using SwiftUI.
